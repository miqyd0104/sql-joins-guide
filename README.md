## Run in VS Code

1. Open this folder in VS Code.
2. Use the SQL Server (MSSQL) extension to connect to your training server.
3. Open either SQL file and choose the Northwind database.
4. Run the entire simple examples file, or select and run an individual exercise query.

The exercises use SQL Server syntax, including `TOP`, `WITH TIES` and `[Order Details]`. Other database engines may need changes. The SQL files contain no credentials and make no permanent changes to Northwind.
